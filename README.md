# 角角探險隊｜小二數學 2S2

免登入、免安裝的互動冒險遊戲。開啟 `index.html` 即可使用；GitHub Pages 會從 `main` 分支根目錄發佈。

## 課堂使用

- 對象：小二「角和垂直線」，約 30–35 分鐘。
- 五站：找頂點與比較邊長 → 用直角工具 → 辨認銳角、直角、鈍角與垂直線 → 親手畫角與垂線 → 新方向遷移題。
- 建議學生手邊有三角尺和紙筆；螢幕上畫完後，請再用真實工具畫、驗證一次。
- 畫圖使用手指或滑鼠拖動橙色控制點；電腦也可聚焦控制點，以方向鍵每次調整五度。
- 完成畫圖後可在成果卡看到作品。遊戲不會收集姓名、上傳作品或顯示公開排名；關閉頁面後成果不會保存。

## ClassDojo

此遊戲不連接 ClassDojo 帳戶。教師可按成果卡及學生口頭解釋，在 ClassDojo 建立並核實以下自訂技能，每項每課最多一次：

| 技能 | 建議證據 |
| --- | --- |
| 我會驗證 | 對準頂點，用直角工具比較開口 |
| 我會解釋 | 說出角的大小看開口，並說出垂直線的判斷理由 |
| 我會畫和修正 | 畫出所需的角，檢查後能修正 |
| 我會靈活運用 | 面對旋轉的新圖例仍能判斷或畫出直角 |

不因答錯扣分；重玩不會自動產生 ClassDojo 分數。

## 教學與技術備註

- 依據教育局《小學數學科學習內容》2S2：角的概念、比較大小、直角與垂直線、銳角與鈍角、繪畫角及垂線。課內不要求使用角度單位。
- 題目特意加入邊長不同、圖形旋轉及「相交但不垂直」的反例。
- 畫角檢查使用幾何規則；為方便觸控，直角允許小幅度誤差，應由教師再用三角尺核實。
- 沒有學生資料、分析服務、外部 API 或 ClassDojo 自動加分。只從 Google Fonts 讀取字型；未能連線時使用裝置字型。
